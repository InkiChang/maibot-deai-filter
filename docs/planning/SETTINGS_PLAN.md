# MaiBot 个人拟人插件：设置页面规划

**状态：** 页面信息架构与设置项规划；不是 WebUI 原型、后端接口或已实现功能。页面及字段最终须按 MaiBot 1.4.5 实际插件配置能力校准。
**使用范围：** 仅本人微信个人私聊；不配置群聊。日常对话不承担设置、记忆审核或管理命令。

## 设计原则

1. 设置分为“安全必需”“拟真行为”“模型与成本”“诊断维护”；普通用户先能完成最小启用，进阶参数收在折叠区。
2. 每项设置均显示：名称、当前值、明确作用、默认值/建议值、影响范围；有风险的选项说明可能后果。
3. 主回复由 MaiBot Replyer 管理；SubQ 决策模型在插件独立模块配置；记忆整理/生活生成等其他模型任务可复用 MaiBot 已配置模型。SubQ 密钥只能通过安全凭据/环境变量引用，不在普通配置、日志或 Git 中保存明文。
4. 不提供与 MaiBot 原生 `[personality]` 重复的人设编辑器。稳定人格仍在 MaiBot 原生位置维护；本插件只配置动态状态与调制幅度。
5. 默认不开启主动消息；默认不在微信中弹出任何配置或记忆审批。

## 页面总览（建议 7 个一级页面）

| 页面 | 主要用途 |
|---|---|
| 1. 总览 | 看运行状态、功能开关、近期开销与告警；快速判断插件是否正常。 |
| 2. 私聊接入 | 限定本人微信私聊身份及注入范围，保护个人数据边界。 |
| 3. 对话拟真 | 配置动态状态如何影响表达，以及表达检查策略。 |
| 4. 生活与内容 | 配置角色日常推进节奏、天气/新闻素材、行为策略与梦境频率。 |
| 5. 记忆与隐私 | 配置后台记忆候选处理、写入授权、留存和清理规则。 |
| 6. 模型连接与预算 | 配置插件独立的 SubQ 决策模型，并为记忆整理/生活生成选择可复用的 MaiBot 模型；设置调用门槛、token/费用/重试预算与失败降级。 |
| 7. 诊断与评测 | 检查 Prompt 注入、成本、错误与拟人回归测试，不存不必要聊天原文。 |

---

## 1. 总览

- **插件总开关**：停用时不读取状态、不注入提示、不调用 SubQ；保留数据但停止运行，避免误以为卸载即删除数据。
- **运行模式**：`关闭 / 影子观察 / 正常运行`。影子模式只计算并记录决策理由，不改变回复；用于上线前验证。
- **当前覆盖范围**：只读展示“本人微信个人私聊”；不提供群聊开关。
- **功能状态卡**：显示人格调制、生活世界、后台记忆、SubQ、表达检查各自启停及最近一次成功运行时间。
- **今日用量**：按任务模型槽位展示模型调用数/token/估算费用、搜索请求数、注入上下文 token 增量、重试次数与失败数；用于发现费用或上下文异常。
- **最近告警**：展示脱敏的错误类别、所涉任务模型槽位和恢复建议；不展示凭据或完整聊天内容。
- **快速安全停用**：停止本插件的运行时行为，不删除 MaiBot 人设或历史数据；真正数据删除走后台维护流程。

## 2. 私聊接入

- **允许的平台**：固定为 MaiBot 实际微信适配器；作用是防止 QQ 等其他平台误注入，首版不做多平台选择。
- **本人用户 ID / 白名单**：指定唯一允许的微信身份；未匹配时 fail-closed，不读取拟人状态、不调用模型。
- **私聊校验**：必须同时满足“本人 ID 匹配”和“事件为个人私聊”；不以插件自己的白名单代替平台事件类型校验。
- **会话绑定策略**：选择允许的本人 session 标识或由适配器动态识别；作用是防止跨会话状态混用。具体字段要在 1.4.5 微信事件验证后定。
- **拒绝事件的处理方式**：默认直接交还 MaiBot 原流程或按接入 Hook 能力安全拒绝；不让本插件给群聊/他人消息生成注入内容。必须先验证 Hook 能否安全做到。
- **诊断注入范围**：可开关记录“事件是否通过过滤、注入了哪些模块 ID”的脱敏元信息；不记录完整消息正文。

## 3. 对话拟真

- **动态调制总开关**：启用短期情绪/精力/关系信号对表达的轻量影响；关闭时仍使用 MaiBot 原生人格回复。
- **状态影响强度**：建议 `弱 / 中 / 强`，控制动态状态影响口吻的幅度；默认弱，避免角色每次情绪波动都大幅变脸。
- **可参与表达的状态维度**：情绪、精力、压力、无聊、关系熟悉度分别开关；作用是将状态变量映射为回答风格信号，不是心理诊断。
- **状态信号注入上限**：限制每轮最多加入几条短表达指令，避免状态卡膨胀占用上下文；默认仅注入最相关的 1–3 条。
- **表达调制内容**：选择可用信号类型，例如“略轻松/略谨慎/简短回应/延续当前话题”；不得覆盖 MaiBot 身份、价值观、底线，也不设“假装真人/否认 AI”选项。
- **主动扩展倾向**：`低 / 中 / 高`，仅控制回复中是否自然延伸相关话题；不是后台主动发消息，首版默认低。
- **回复长度倾向**：`跟随对话 / 简短 / 适中`，控制拟人表达的平均篇幅，不做字符硬截断。
- **自然口语处理**：控制语气词、短句、分条等表达倾向；默认克制，不强制错别字、口吃或固定口头禅。
- **生成后质量检查**：启用后只检查套话、重复、明显过长或与当前情境冲突；默认规则检查，最多重试一次，避免无限重写。
- **拆分发送**：独立开关及拆分倾向；仅在 MaiBot 发送接口可靠时使用，不改变语义、不强行拆成多条。

## 4. 生活与内容

- **角色生活总开关**：允许后台推进角色自己的日程、事件与连续生活经验；关闭后暂停新生活事件生成及注入，已有经历可保留。开启时角色可自然以第一人称回忆，不在日常对话中提示“这是模拟”。
- **角色时区与生活节奏**：定义角色日常采用的时区、作息和生活事件推进速度；用于让生活经历与用户所处环境合理衔接，不代表插件能代替角色完成现实物理活动。
- **每日生活事件上限**：限制后台每天为角色推进的新生活事件数量，避免时间线过满、重复和上下文噪声；默认少量，可设为 0 以暂停新事件。
- **事件连续性强度**：`保守 / 平衡 / 活跃`，控制新事件引用旧事件、承接未完成事项的程度；越活跃越需验证时间线。
- **天气素材**：总开关、地点来源（用户配置地点或明确禁用）、刷新有效期；可融入角色当天环境和生活经验。后台保留地点与更新时间，过期素材不注入；用户询问现实中的实时天气时，按当前可验证来源回答，不将陈旧缓存说成实时观测。
- **新闻话题素材**：总开关、兴趣分类、每日搜索批次/条数上限、缓存时长；带来源与发布时间的内容可融入角色当天关注和生活经验，不因聊天逐条搜索。过期素材停止注入；明确询问现实新闻事实时按可验证来源作答。
- **搜索工具选择**：从 MaiBot 已安装并验证可调用的搜索插件/工具中选择；若无稳定接口，页面显示不可用并跳过，不伪造成功结果。
- **行为策略库**：总开关、每次最多检索条数（建议 0–1）；用于在特定聊天情境选接话策略，不是百科，也不把建议写成角色经历。
- **梦境生成**：总开关、低频计划（预算不足时跳过）、高发散强度；梦境作为角色自己的梦境经验，可自然回忆并弱影响情绪。后台用 `experience_type=dream` 与用户现实事实分账，避免作为现实物理行动证据。
- **主动生活分享**：首版固定关闭或标注“尚未实现”；未来若纳入，须单独启用、限本人私聊、配置安静时段/冷却/每日上限，不与本页日程生成开关混为一谈。

## 5. 记忆与隐私

- **短期摘要开关**：保存有限话题与待续事项，帮助跨轮连贯；关闭则只依赖 MaiBot 当前会话上下文。
- **短期摘要容量/保留期**：限制摘要长度与过期时间，控制隐私和 prompt 体积。
- **事实候选后台处理**：异步整理用户明确提供的事实，不在聊天中弹出审核；开关关闭时不提取新的事实候选。
- **自动写入授权类别**：逐类选择允许自动沉淀的低风险事实（例如明确稳定偏好）；敏感、含糊、矛盾内容始终静默隔离，不因模型置信度高而越权。
- **A-Memorix 接口状态**：只读显示“未验证/可用/不可用”；未验证或未获支持时禁止自动写入，候选仅保留在本地待处理区。不能通过设置页绕过受支持 API 直接写 SQL。
- **候选保留期**：控制未解决候选在本地保留多久，过期自动清理；作用是避免无限积累敏感数据。
- **角色经验与用户事实分账**：固定开启且不可关闭；角色日常、梦境和资讯经历保存在角色生活账，不写入 A-Memorix 用户事实。该分类仅供后台治理，不改变角色对自身经历的自然叙述。
- **日志最小化**：选择仅记录决策码/事件 ID/哈希，默认不存完整聊天原文；保留期可配置并显示预计影响。
- **删除策略**：规划后台数据清理入口，按类别清理短期摘要、角色生活经历、记忆候选和日志；属于后续维护能力，不通过微信命令操作。

## 6. 模型连接与预算

- **主回复模型**：只读显示“由 MaiBot Replyer 当前配置负责”；插件不覆盖、不复制主回复模型设置。
- **SubQ 独立模型模块**：首版协议候选为非流式 OpenAI Chat Completions wire format，可配置 Provider 标识、Base URL、模型名、密钥环境变量名/安全凭据引用和超时；仅用于低频歧义/重要决策，不依赖 MaiBot 普通模型清单。协议候选不等于服务兼容承诺；尚无真实 Provider 实测。不得在 TOML 中填密钥明文。模块总开关默认关闭。
- **SubQ 凭据生命周期**：配置仅保存环境变量名/安全仓库引用；UI 只显示引用名与“已配置/缺失”，不回显密钥。运行时缺失/读取失败时拒绝调用并保持关闭，不回退到其他模型或密钥。轮换在安全凭据源更新后刷新/重启插件；撤销先吊销服务端密钥，再删除本地引用并验证诊断与日志不含凭据。
- **记忆整理模型**：可选 MaiBot 已配置模型，用于后台批次事实候选抽取/语义冲突辅助；也可设为“禁用模型（仅规则）”。该槽位与 SubQ 独立模型连接分开。
- **生活生成模型**：可选 MaiBot 已配置模型，用于低频生活日结、事件和梦境生成；也可设为“禁用模型”或与记忆整理任务共用。该槽位不改变 SubQ 的独立 Provider 配置。
- **模型状态**：分别显示 SubQ 独立连接的诊断状态，以及 MaiBot 普通模型调用接口/已选模型的可用状态；未验证或不可用时清楚说明，不声称连接成功。SubQ 凭据只显示变量名/引用是否配置，不显示明文。
- **任务总开关与触发场景**：分别启用 SubQ、记忆整理、生活生成；明确直答、状态衰减、普通检索默认不触发模型。
- **调用门槛与单次 token 上限**：控制 SubQ 何时升级判断、每个任务可发送的上下文和输出长度；SubQ 输出限短 JSON，后台任务按摘要模板限长。
- **日请求数/token/费用预算**：SubQ 独立预算；MaiBot 普通模型任务按任务或可用宿主维度统计。达到限额后停止或降级对应任务，不通过更换凭据规避服务限制。
- **SubQ 超时与重试**：只配置 SubQ 独立客户端的超时、最大额外重试次数（建议 1 次，总尝试最多 2 次）、退避基数/上限与总耗时预算；仅对超时、连接中断、服务端 5xx 等暂时性错误重试。尊重 `Retry-After`；429/配额限制按服务商要求等待，不更换凭据规避；认证、权限、模型不存在及参数错误不重试。JSON 格式错误最多允许一次受预算约束的修复请求。MaiBot 普通模型调用按宿主自身重试策略，不叠加插件重试。
- **失败降级**：SubQ 失败则回退确定性规则，不阻塞主流程；主聊天仍由 MaiBot Replyer 正常生成。记忆/生活后台任务失败时标记待重试或跳过，不凭不完整结果写库。
- **幂等与缓存**：对重复任务复用有效结果；写入使用批次/任务 ID 防止重试导致重复保存。仅模型请求可安全重跑，不能重放已完成的有副作用写入。
- **影子模式**：仅记录插件任务的判断草案、不影响实时回复；用于验证模型槽位、触发阈值、成本和重试参数。

## 7. 诊断与评测

- **最近运行记录**：时间、模块、事件 ID、耗时、结果码；默认不展示完整消息正文。
- **Prompt 注入检查**：以脱敏快照查看哪些模块进入微信 prompt、估算新增 token，验证没有向非本人/群聊注入。
- **费用与延迟图表**：按任务模型槽位和日期查看请求数、token/估算费用、搜索次数、回复延迟、错误类别与重试率，便于定位具体任务的成本和稳定性。
- **回归测试集**：提供合成/脱敏场景（直接问句、歧义、拒绝边界、记忆冲突、梦境与清醒经验区分、新闻过期、现实行动能力询问等），比较开启前后漏答、套话、重复，以及外部事实与能力边界是否准确。
- **运行诊断**：检查微信事件类型识别、Hook 注入点、搜索工具、A-Memorix 接口、SubQ 独立 Provider 连接及 MaiBot 普通模型调用接口/选择状态；未验证项显示原因，不显示虚假的“已连接”。
- **导出诊断摘要**：导出不含密钥和完整聊天原文的配置/错误摘要，方便排障。

## 页面之间的推荐使用顺序

1. 先在“私聊接入”验证本人身份与微信单聊事件识别。
2. 在“模型连接与预算”配置 SubQ 独立连接、选择其他任务的 MaiBot 模型并设预算；先开启影子模式。
3. 在“对话拟真”启用弱调制和有限上下文，比较前后效果。
4. 再逐项启用“生活与内容”；先少量天气/新闻素材，不立即开启梦境或主动分享。
5. 最后启用记忆候选后台处理；只有 A-Memorix 支持接口验证通过、自动写入类别授权明确后才开放写入。
6. 全程在“诊断与评测”观察 prompt 增量、成本、漏答与重复；任一超预算自动降级。

## 首版页面范围建议

页面架构先定为 7 页，但首个可用配置版本可只实现：总览、私聊接入、对话拟真、模型连接与预算、诊断与评测。SubQ 独立模型模块首版需包含基本连接与密钥安全配置；生活资讯、梦境及 A-Memorix 自动写入在接口未验证前显示为“规划中/不可用”，不呈现可误导用户的生效开关。
